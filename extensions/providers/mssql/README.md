# Microsoft SQL Server

Microsoft SQL Server on Kubernetes, wrapped as an OpenEverest provider and
delivered commercially by [Solanica](https://solanica.io/mssql-on-kubernetes).

Supports standalone instances and Always On availability groups, with automated
backups and restores.

## Access

This is a **gated** extension. It is listed here for discovery only — it cannot
be installed directly from the public hub. A commercial license and private
registry credentials are required.

To get access, contact Solanica:

- **Request access:** https://solanica.io/contact-us?utm_source=hub-mssql
- **Sales:** sales@solanica.io

Once you have a license and credentials, Solanica provides the chart reference
and install instructions.

## Capabilities

- High availability via Always On availability groups
- Automated backups and restores, with point-in-time restore
- TLS encryption, enabled by default
- Prometheus monitoring via `sql_exporter`
- Standalone and clustered topologies
